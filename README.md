# Opera Omnia Ex Nihilo

Minecraft 1.7.10 向けの SkyBlock MOD。Fundamentum と Cribrum で木材と葉から最初の篩まで進める。Materia は JAOPCA が検出した金属をホワイトリストで絞り、環境に登録済みの加工形態を参照する。

## 開発クライアントを起動する

JDK 25 でリポジトリのルートから実行する。

```sh
VERSION=0.0.0-dev ./gradlew runClient25
```

ビルド構成と必要な MOD は [開発環境と起動](docs/getting-started.md)、ゲーム内の手順は [木から最初の篩まで](docs/playtest.md) を参照。
