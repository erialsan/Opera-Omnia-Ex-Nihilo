# Opera Omnia Ex Nihilo

**English** · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

A SkyBlock mod for Minecraft 1.7.10. With Fundamentum and Cribrum, you can start with wood and leaves and work your way up to your first sieve. Materia filters the metals detected by JAOPCA through an allowlist and looks up the processing forms already registered in your mod setup.

## Run the development client

Run this command from the repository root with JDK 25.

```sh
VERSION=0.0.0-dev ./gradlew runClient25
```

The development guide covers the build setup and required mods. The playtest guide walks through the in-game steps. Both guides are in Japanese. [Development setup](docs/getting-started.md) · [From wood to your first sieve](docs/playtest.md)
