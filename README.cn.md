# Opera Omnia Ex Nihilo

[English](README.md) · [日本語](README.ja.md) · **简体中文**

这是一款适用于 Minecraft 1.7.10 的 SkyBlock 模组。借助 Fundamentum 和 Cribrum，你可以从木材和树叶起步，做出第一台筛子。Materia 使用白名单筛选 JAOPCA 检测到的金属，并查找当前模组环境中已经注册的加工形态。

## 启动开发客户端

使用 JDK 25，在仓库根目录运行以下命令。

```sh
VERSION=0.0.0-dev ./gradlew runClient25
```

开发指南介绍构建配置和所需模组，游玩指南介绍游戏内的操作步骤。两份指南均为日文。 [开发环境与启动指南](docs/getting-started.md) · [从木材到第一台筛子](docs/playtest.md)
