# 木から最初の篩まで

同梱の `ooen_fundamentum` と `ooen_cribrum` で、木材と葉から小麦の種まで進める。通常のサバイバルワールドか、木がある SkyBlock ワールドで試せる。

クリエイティブでは、木のクロークが目印の **Opera Omnia Ex Nihilo** タブからアイテムとブロックを取り出せる。

1. 棒4本で木のクロークを作る。左上2マスと、その右側の列を下まで埋める。クロークで通常の葉を壊すと、苗木とリンゴを合計4回抽選し、シルクワームが別枠で10%の確率で落ちる。バニラではオークかダークオークの葉からリンゴが1個以上落ちる確率は、幸運なしで約1.985%。葉ブロックを回収するにはハサミを使う。
2. シルクワームを持って、ワールドにある葉を右クリックする。虫食いは 0% から約1秒ごとに10ポイントずつ進み、100% になると葉が白くなり、隣接する葉にも広がる。Waila を入れている場合は、葉に照準を合わせると進行度が見える。100% の葉をクロークで壊して糸を集める。作業台の中央に棒を置き、上下左右を糸で囲ってメッシュを作る。
3. 同じ木材の板材6枚とハーフブロック1枚で堆肥バレルを作る。作業台の左右の列に板材を置き、下段中央にハーフブロックを置く。苗木、リンゴ、葉ブロック、作物などを合計8個入れ、約10秒後に素手で右クリックして土を回収する。植え直す苗木は先に取っておく。Waila では投入量と堆肥化の状態を確認できる。 [同梱の投入物リスト](../src/main/resources/ooen/fundamentum/plant_inputs.json)
4. 篩の枠は作業台の上段左右と中段に同じ種類の板材、下段左右に棒を置いて作る。枠を置き、メッシュ、土の順に右クリックで取り付ける。右クリックを押し続けるか、間隔を空けて10回右クリックすると小麦の種が1個と小石が落ちる。振るう間隔は4 tick（通常0.2秒）。

バレルと篩の対応木材は、オーク、マツ、シラカバ、ジャングルの木、アカシア、ダークオーク。
バレルには開いた口があり、投入した葉や完成した土が縁の内側に見える。
篩は脚付きの開いた木枠で、メッシュは縁より少し低い位置に張る。投入した素材はその上に表示される。
素手でスニークしながら篩を右クリックすると、メッシュと残っている投入素材を回収でき、篩は空の枠になる。

篩を同じ高さに並べて中央を右クリックすると、縦横それぞれ2マス先までの5×5の篩をまとめて使える。素材を入れるときは、中央から先に同じティアの空き篩へ、手持ちから1個ずつ配る。振るうときは、中央とメッシュティア・素材・進捗が一致する篩がそれぞれ1回進む。

メッシュは糸 → 火打ち石 → 鉄 → 金 → ダイヤモンド → エメラルドの順に強化できる。作業台の中央に直前のメッシュを置き、上下左右を次の素材4個で囲む。鉄と金にはインゴットを使う。ネザライトインゴットが OreDictionary に登録されている環境では、同じ手順でエメラルドからネザライトへ強化できる。

### 篩のドロップ

上位メッシュは下位のドロップを引き継ぐ。火打ち石は鉱石ティア1、鉄は2、金は3、ダイヤモンド・エメラルド・ネザライトは4まで扱える。糸メッシュでは土から小麦の種、砂利から火打ち石、塵から火薬が出る。投入した素材はメッシュと一緒に保存される。

土からは小麦の種と小石に加え、草の種が10%、菌糸の胞子・ニンジン・ジャガイモが各5%で出る。草の種と菌糸の胞子を通常の土に右クリックで使うと、それぞれ草ブロックと菌糸ブロックに変わる。対応するビートルートや種が登録されていれば、それぞれ5%で出る。抽選は品目ごとに行う。

砂利・砂・塵からそれぞれ鉱石砂利・鉱石砂・鉱石塵の小片が出る。投入するたびに、使える鉱石ティアごとに独立して抽選し、当たったティアの有効な金属から1種を選ぶ。ティア1は鉄・錫・銅、ティア2は金と未指定の金属、ティア3はウラン、ティア4はイリジウム・タングステン・チタン・ネザライト・ドラコニウム。同じ小片4個を作業台で 2×2 に並べると設置できる鉱石ブロックになり、かまどでインゴットにできる。

宝石は OreDictionary に登録された現物が出る。ダイヤモンドはティア3、エメラルドは4、その他の宝石は2から。レッドストーン・骨粉は火打ち石以上、グロウストーンダスト・ブレイズパウダーは鉄以上で塵から出る。宝石と粉は品目ごとに抽選する。投入素材と確率は [同梱ドロップ表](../src/main/resources/ooen/cribrum/sieve_drops.json)、金属の分類は [鉱石ティア表](../src/main/resources/ooen/cribrum/metal_tiers.json) を参照。

金床の左にメッシュ1個、右に幸運または効率強化のエンチャント本を置くと、メッシュに適用できる。幸運で当選した品目は1～4個になり、最大個数は幸運レベル＋1。効率強化は1回の進捗にレベルごとに5ポイントを加え、効率強化 V なら3回で完了する。メッシュを外す、篩を壊す、メッシュを強化する場合もエンチャントを引き継ぐ。

開発クライアントの統合サーバーでは、サバイバルでのクラフト、葉の採取、成熟と堆肥化、土からの種の回収までを通して確認した。

## Malleus のハンマー

作業台で、上段中央と中段右に素材、中段中央と下段左に棒を置く。素材は板材、丸石、鉄インゴット、ダイヤモンド、エメラルドのいずれか。ネザライトインゴットが OreDictionary に登録されている環境では、ネザライトのハンマーがクリエイティブタブに出る。ネザライトの鍛冶レシピは後の実装。

サバイバルでハンマーを持って丸石を壊すと砂利、砂利を壊すと砂、砂を壊すと篩に入れられる塵が1個落ちる。

Materia の鉱石砂利をハンマーで壊すと、同じ金属の小さい鉱石砂が4個か5個、同じ確率で落ちる。金床の左にハンマー、右に幸運のエンチャント本を置くと幸運を付けられる。鉱石砂利の粉砕には篩と同じ幸運の倍率がかかり、幸運 III では最大20個になる。

## Transmutatio の樽とるつぼ

1. 土を篩うと、通常は小石が2～6個出る。確定2個に加え、50%の抽選2回と10%の抽選2回をそれぞれ行う。小石4個を2×2に並べると丸石1個になる。
2. 同じ樹種の原木7個を大釜と同じ形に並べると、木のるつぼになる。堆肥バレルと同じ投入物を合計4個入れると、熱源なしで水1杯（1,000 mB）に変わる。空のバケツで回収する。
3. 木の樽か石の樽に水を入れ、塵を1個投入する。素手で右クリックすると粘土ブロックを取り出せる。石の樽は作業台の左右の列に石を3個ずつ置き、下段中央に石ハーフブロックを置いて作る。
4. 粘土玉1個と骨粉1個で磁器粘土を作る。磁器粘土7個を大釜と同じ形に並べ、未焼成の磁器るつぼを作ってかまどで焼く。
5. 磁器るつぼの真下に熱源を置き、丸石4個を投入して溶岩1杯を作る。空のバケツで回収する。両方のるつぼは処理中の素材と液体を合わせて4,000 mBまで入る。
6. 石の樽に溶岩を入れ、レッドストーン1個でネザークォーツ、グロウストーンダスト1個でエンドストーンを作る。素手で右クリックすると取り出せる。

磁器るつぼは毎 tick、松明で1 mB、火で2 mB、溶岩で3 mB、ウラニウムブロックで10 mB、プルトニウムブロックで20 mB、Awakened Draconium Block で120 mBを変換する。追加 MOD の熱源は OreDictionary で照合する。 [同梱の熱源表](../src/main/resources/ooen/transmutatio/crucible_heat_sources.json)

## Vita のじょうろ

作業台の上段左、中段左と中央、下段中央と右に素材を置き、中段右に棒を置く。素材はハンマーと同じ。ネザライトはインゴットが登録されている環境のクリエイティブタブに出る。

| 素材 | 容量 | 散水範囲 |
| --- | ---: | ---: |
| 木 | 1,000 mB | 1×1 |
| 石 | 2,000 mB | 3×3 |
| 鉄 | 4,000 mB | 5×5 |
| ダイヤモンド | 8,000 mB | 7×7 |
| エメラルド | 16,000 mB | 9×9 |
| ネザライト | 64,000 mB | 11×11 |

水源に向けて右クリックすると最大1,000 mBをくみ取る。作物・苗木・耕地に向けて右クリックを長押しすると、同じ高さの範囲に散水して成長を促し、耕地を湿らせる。1回の散水につき1 mBを消費し、散水間隔は4 tick。残量と範囲はアイテムのツールチップで確認できる。

起動手順は [開発環境と起動](getting-started.md) を参照。

シルクワームの使い方と葉への広がり方は [Ex Nihilo Wiki の Silkworm](https://ftb.fandom.com/wiki/Silkworm) と [作者の解説](https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/1291850-ex-nihilo-the-skyblock-companion-mod) を参照。
